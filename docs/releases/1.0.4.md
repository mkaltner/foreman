# Foreman v1.0.4

Foreman v1.0.4 is the updater-enabled bootstrap release for the 1.x series. It
adds recoverable server updates and verified Android APK self-update, while
also improving long-session composer performance and copy feedback.

## Highlights

- Adds one authenticated, recoverable server updater shared by the CLI, web,
  and Android, with signed artifact verification, active-session safety,
  durable progress, external activation, health checks, and rollback.
- Lets Android download the exact official APK, verify the signed checksum and
  APK signer, request per-app installer permission when required, and hand the
  verified package to Android's system installer for explicit confirmation.
- Prevents unchanged transcript Markdown and activity rows from rerendering on
  every composer keystroke, eliminating the severe typing lag seen in long
  sessions.
- Adds consistent 1.5-second checkmark feedback and accessible status labels to
  web and Android copy controls.
- Hardens tagged releases by resolving unpublished drafts through their
  authenticated API URL and explicitly promoting stable releases as latest.

## Bootstrap update and install

The v1.0.3 tag predates both managed updaters. Existing v1.0.3 Linux and Android
installations must therefore move to v1.0.4 manually once. After v1.0.4 is
installed, its managed update paths can be used for later compatible releases.

For Linux, verify the signed checksum manifest, extract
`foreman-linux-v1.0.4.tar.gz`, and run `./install.sh`. Subsequent releases can be
checked and installed with:

```sh
foreman update --check
foreman update
```

Authorized full-access web and Android clients can initiate the same server
update from Settings → About. Foreman refuses activation while sessions or
approval/input state make a restart unsafe.

For Android, manually install `foreman-v1.0.4.apk` over v1.0.3. This release uses
version name `1.0.4`, advances Android to version code 11, and retains the
established signing certificate. Later complete stable APKs can be downloaded,
verified, and opened in Android's system installer from Settings → About.

## Release artifacts

The release contains exactly five custom assets:

- `foreman-linux-v1.0.4.tar.gz`
- `foreman-v1.0.4.apk`
- `SHA256SUMS`
- `SHA256SUMS.sig`
- `foreman-release-cert.pem`

Verify the detached manifest signature and both payload checksums before manual
installation. The tagged workflow repeats release metadata, signer, archive,
checksum, and downloaded-payload verification before publication.

## Compatibility

- Protocol version remains v1.
- Android requires API 23 or newer and remains sideload-only.
- Android version code advances monotonically from 10 to 11.
- The Android application ID and signing-certificate fingerprint are unchanged.
- Server updates preserve configuration, paired-client state, and durable
  session metadata, and retain rollback material until activation is healthy.
