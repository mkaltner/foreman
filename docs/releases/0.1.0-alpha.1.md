# Foreman v0.1.0-alpha.1

Foreman is a small Linux user service and Android companion app for viewing and
controlling local Codex sessions from a phone.

## Install

On the Linux host:

```sh
git clone https://github.com/mkaltner/foreman.git
cd foreman
./install.sh
foreman status
foreman pair
```

On Android, download and sideload `foreman-v0.1.0-alpha.1.apk` from this
release, then enter the Linux host, six-digit pairing code, and a device name.

## Included

- persistent authenticated device pairing;
- repository discovery and Codex session list/read/start/resume;
- prompt, steer, interrupt, archive, and delete controls;
- live assistant, tool activity, status, reconnect, and notification updates;
- installed model, reasoning-effort, and access selection;
- up to four bounded image attachments per message;
- system, light, and dark themes with a configurable accent.

## Security warning

Use Foreman only on a trusted LAN or through Tailscale, WireGuard, or another
secure tunnel. Device authentication prevents unauthenticated requests but does
not encrypt the direct TCP connection. Never expose port 8765 to the public
internet.

## Known limitations

- Approval and structured-input requests must be answered in another Codex
  client.
- Direct TCP transport is not encrypted.
- Live co-presence with Codex Desktop requires successful attachment to the
  shared Desktop socket. Otherwise Foreman uses an independent owned runtime
  and reports `SHARED_DESKTOP_LIVE_STATUS_UNAVAILABLE`.
- Android installation is by sideloaded release APK.
- This is an alpha; compatibility and behavior may change between releases.

## Upgrade

```sh
cd foreman
git pull
./install.sh
```

Reinstalling is transactional. If service activation fails, the installer
restores the previous service payload, launcher, and systemd unit.

Report defects with logs, Android version, Linux distribution, Python version,
and `codex --version` at https://github.com/mkaltner/foreman/issues. Do not post
device tokens, pairing codes, prompts, signing data, or other secrets.
