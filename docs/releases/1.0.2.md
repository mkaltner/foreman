# Foreman v1.0.2

Foreman v1.0.2 adds session context and account-usage visibility while retaining
protocol version 1.

## Included work

- Shows bounded session context-window usage and route details.
- Shows bounded provider account-usage information where available.

See the [GitHub release](https://github.com/mkaltner/foreman/releases/tag/v1.0.2)
and [full comparison](https://github.com/mkaltner/foreman/compare/v1.0.1...v1.0.2).
