# Foreman v1.1.1

Foreman v1.1.1 is a focused patch for release discovery in the web client.

## Fixes

- **Immediate update-check results.** Selecting **Check again** now replaces the
  stale connection snapshot immediately, so About shows the newly discovered
  release without requiring a page reload.
- **Host-safe refreshes.** A release check that finishes after the active host
  changes no longer updates the newly selected host with the previous host's
  result.

## Release assets

- `foreman-linux-v1.1.1.tar.gz`
- `foreman-v1.1.1.apk`
- `SHA256SUMS`
- `SHA256SUMS.sig`
- `foreman-release-cert.pem`

The Linux archive and Android APK are accepted only when their checksums and
the signed release manifest validate against Foreman's pinned release
certificate.
