# Foreman v1.0.3

Foreman v1.0.3 expands the web and Android control surfaces and improves session
continuity and notifications. It is the first patch release produced by the
hardened five-asset release workflow.

## Highlights

- Adds authenticated release discovery so web and Android can report newer
  complete stable releases without installing them.
- Adds per-session context usage and global provider-account usage meters.
- Adds repository-grouped, collapsible session lists with durable per-host
  state and reduced redundant provider/repository labels.
- Adds archived Codex session discovery and restore on web and Android while
  preserving the user's selected discovery filters.
- Adds curated, coordinated themes across web and Android.
- Restores pending approvals, immutable session configuration, accurate
  timestamps, active work, and the last-opened session across reconnects and
  relaunches.
- Improves Android navigation and consolidates background monitoring into one
  persistent notification.
- Suppresses redundant completion/attention notifications only while another
  client is visibly focused on the same session.
- Adds About/version information and release-update availability to both
  clients.

## Update and install

The shared recoverable server updater is not included in the v1.0.3 tag; it
first ships in v1.0.4. Update a v1.0.3 server manually by verifying the signed
checksum manifest, extracting the Linux archive, and running `./install.sh`.

For a manual install, verify the signed checksum manifest before extracting the
Linux archive and running `./install.sh`.

Android users can install `foreman-v1.0.3.apk` over v1.0.0 or a compatible prior
build. This release uses version name `1.0.3`, monotonically advances Android to
version code 10, and retains the existing signing certificate. Android APK
self-update is not included in this release.

## Release artifacts

The release contains five assets:

- `foreman-linux-v1.0.3.tar.gz`
- `foreman-v1.0.3.apk`
- `SHA256SUMS`
- `SHA256SUMS.sig`
- `foreman-release-cert.pem`

Verify both the signature and checksums before installation. The tagged release
workflow validates the signed APK metadata and certificate, archive contents,
published asset set, and downloaded payload before publishing the release.

## Compatibility

- Protocol version remains v1.
- Android requires API 23 or newer and remains sideload-only.
- Server updates preserve Foreman configuration, paired-client state, and
  durable session metadata.
- Android APK downgrades remain unsupported because version codes are
  monotonic.
