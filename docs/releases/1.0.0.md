# Foreman v1.0.0

Foreman 1.0 is the first stable release of the self-hosted, LAN-first control
plane for monitoring and controlling Codex sessions from Android and the web.
It establishes protocol v1 and the documented state-preserving Linux upgrade
behavior as the supported compatibility contract for the 1.x series.

## Highlights

- Monitors active, waiting, failed, stale, and recently completed Codex work
  from Android and responsive web clients.
- Supports prompts, steering, interrupts, image input, approvals, structured
  input, session search, model selection, reasoning effort, and access levels.
- Provides bounded client-local multi-host overviews while keeping tokens,
  search, conversations, active monitoring, and notifications host-scoped.
- Supports shared Codex Desktop live status when attachment is available and an
  explicitly reported independent fallback runtime when it is not.
- Preserves configuration, paired-client state, and tokens across transactional
  Linux upgrades, including rollback after service activation failure.
- Aligns Linux, web, and Android metadata at `1.0.0`, retains protocol v1, and
  advances Android to version code 9.

## Install and upgrade

Verify `SHA256SUMS` before using either release asset. Linux users can install
from the tagged archive or a verified tag checkout and run `./install.sh`.
Upgrades preserve `~/.config/foreman/foreman.env` and
`~/.local/state/foreman`, including paired-client state.

Android users can install the signed `foreman-v1.0.0.apk` over the prior alpha
or release candidate to preserve encrypted saved-host tokens. Confirm version
name `1.0.0`, version code 9, and signing certificate SHA-256
`80d479d1a8f9f038c6977a1cfb68a2b45c3117492c364620e48babebf1810ad3`.

## Compatibility and product boundaries

- Protocol v1 is supported throughout the 1.x series; see
  `docs/compatibility.md` for the versioning and upgrade policy.
- Direct TCP and HTTP are authenticated but unencrypted. Use a trusted LAN,
  Tailscale, WireGuard, or a trusted reverse proxy. Foreman does not terminate
  TLS.
- Android distribution is sideload-only. Android 6.0 (API 23) and later is the
  supported platform baseline.
- Chrome and Firefox are supported browsers. Edge is best-effort.
- Multi-host overview data is bounded and client-local. Search, conversations,
  active monitoring, and notifications remain host-scoped.
- Desktop co-presence requires shared-attach mode. Fallback mode is an
  independent runtime.
- Foreman has no cloud relay, persistent audit history, or built-in TLS
  termination.

## Rollback

For Linux, unpack or check out the previously verified release and rerun its
`install.sh`; configuration and paired-client state remain in their existing
user directories. Android cannot downgrade in place to an APK with a lower
version code.
